# Код и сторонние материалы

Лицензия собственного кода пока не выбрана командой. Этот файл не выдаёт разрешение
на использование и не заменяет текст лицензии. До публичного релиза команда выбирает
условия использования своего кода и добавляет соответствующий текст.

| Материал | Источник / условия | Где используется | Действие до релиза |
| --- | --- | --- | --- |
| Python/JS библиотеки | Метаданные пакетов в uv.lock и package-lock.json; лицензия каждого пакета | API, UI, инструменты | B2/F1 сверяют лицензии фактически используемых версий |
| FFmpeg | https://ffmpeg.org/legal.html ; зависит от конфигурации сборки | Будущий рендер в Docker | A1/B2 фиксируют сборку и её условия |
| DejaVu Sans | https://dejavu-fonts.github.io/ ; пакет fonts-dejavu-core | Планируемый шрифт контейнера | A1 сохраняет сведения о лицензии из установленного пакета |
| Синтетический тон | tests/fixtures/generate_tone.py, генерируется кодом проекта | Технические тесты, не песня | A2 записывает параметры в тест-отчёт |

Пользовательские треки и чужие тексты песен сюда не входят. Для музыкального демо
используйте собственный или разрешённый командой материал с описанным источником.
Предоставленные PDF и личные фотографии участников в репозиторий не скопированы.
