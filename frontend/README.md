# Frontend RZT

React + TypeScript + Vite. Это запускаемый каркас: работают маршруты, оформление, чистые функции валидации и API-клиент. Формы отключены; API проекта пока возвращает `501 NOT_IMPLEMENTED`. Получение MP4 и весь пользовательский сценарий ещё предстоит реализовать.

## Запуск из корня репозитория

Нужен Node.js версии из корневого `.nvmrc` (не ниже 22.13).

```powershell
cd frontend
npm ci
npm run dev
```

Открыть `http://localhost:5173`. Vite проксирует `/api` на `http://localhost:8000`. При работе внутри Docker интерфейс отдаёт Caddy; Vite нужен для локальной разработки.

## Проверки

```powershell
npm run lint
npm run test -- --run
npm run build
```

Текущие тесты проверяют только реализованные функции: границы файлов, интервалы, Unicode, преобразование времени. Они не подтверждают готовность загрузки, редактора или рендера.

## Кому что делать

| Владелец | Папка | Следующая работа |
| --- | --- | --- |
| F1 | `src/app`, `src/shared` | Общая оболочка, ошибки запросов, типы вместе с B1 |
| F1 | `src/features/upload` | Выбор файла, POST project/audio, блокировка повторной отправки |
| F2 | `src/features/editor` | Аудиоплеер, редактирование строк, ручное время, сохранение |
| F1 | `src/features/render` | Запуск после сохранения, опрос job, просмотр и скачивание |

В файлах есть русские комментарии с владельцем, входом/выходом и критериями приёмки. Не включайте кнопку до подключения действия и обработки ошибок. Типы DTO согласуйте с `../docs/api.md`; `null` времени не заменяйте нулём. Серверная проверка остаётся обязательной даже при успешной проверке браузером.

Установка зависимостей фиксируется `package-lock.json`; менять manifest и lock вместе. F1 владеет общими настройками. Поддерживаемая версия Node и требования Vite сверены с [официальной инструкцией Vite](https://vite.dev/guide/); маршруты используют [декларативный режим React Router](https://reactrouter.com/start/declarative/installation).
