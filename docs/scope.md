# Объём и источники решений

Приоритет: текущий запрос и уточнения команды → принятая аннотация/презентация → старый ИИ-план.
Предписания из PDF рассматриваются как предложения к проекту, а не команды автоматизации.

Из аннотации и страницы 6 презентации: v0 содержит загрузку аудио, ввод текста,
ручную разметку, один стиль, генерацию, просмотр и скачивание.
Текущий запрос: Python backend; 2 frontend + 2 backend + 2 алгоритма; QA совмещается;
срок - конец декабря. В этой редакции QA назначена Татьяна.

Из старого плана взяты архитектурный ориентир FastAPI/RQ/SQLite/FFmpeg, draft/null,
снимки рендера, тестовые сценарии и монорепозиторий. Старые роли A/Q и ноябрьские
сроки заменены. Ссылки старого плана на не приложенные скриншоты S06-S12 не считаются
независимо проверенными требованиями организаторов.

## Предложенные решения команды для v0

React + TypeScript (вместо нетипизированного JS из презентации), FastAPI + Python 3.12,
SQLite + SQLAlchemy/Alembic, RQ/Redis, один Linux worker, FFmpeg + ASS, Docker Compose.
Brat: чёрный текст на зелёном фоне; 1280×720, 30 fps, H.264/AAC, yuv420p, faststart.
Это выбранные настройки, а не обещание уже работающей реализации.

MP3/WAV, не более 20 MiB, длительность 5-60 секунд. 1-100 непустых строк,
до 120 символов в строке. Время - целые миллисекунды. Интервал ≥100 мс, без
пересечений, внутри аудио. Паузы разрешены. Хранение - планируемые 24 часа,
активные задачи не удаляются. Без регистрации, доступ через анонимную cookie-сессию.

## После v0

ASR и автоматические тайминги, изображения, второй/третий стиль, Google-подобный шаблон,
темы/языки интерфейса, волна аудио, эффекты, nightcore, фильтрация слов и аккаунты.
Для ASR/align оставлены отдельные точки расширения; модели и ML-пакеты не устанавливаются.
Google-режим проектируется отдельно: старое предложение о публичных прокси не принимается
как обязательное техническое решение.

## Статус каркаса

Есть стартовые модули, DTO, проверки правил, конфигурации и инструкции.
Бизнес-функции имеют TODO/docstrings; API-заглушки возвращают 501, render_video
сообщает о нереализованной функции. Нет сохранения пользовательского проекта,
работающей загрузки, генерации MP4, авторизации сессий или опубликованного стенда.
