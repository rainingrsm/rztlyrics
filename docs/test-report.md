результаты будущих проверок ниже не выполнены и не подтверждают готовность v0.

| --- | --- | --- | --- | --- |
| 10 с / 3 строки | NOT RUN | NOT RUN | NOT RUN | NOT RUN |

Приложить ffprobe-вывод, метод проверки кадров, `job_id`, SHA, настройки и железо.
Цели: длительность ±200 мс, строки ±100 мс, 60-секундный рендер до 3 минут;
это ориентиры, не уже измеренные результаты.

## Решение о выпуске

- Открытые P0/P1 основного сценария: **не оценено**.
- Известные ограничения: **заполнить по итогам**.
- Чистый запуск и второй браузер/устройство: **NOT RUN**.
- Решение о релизе: **не принято**.
- Кто подтвердил и на каком SHA: **заполнить**.

При изменении кода после приёмки повторить затронутые сценарии на новом SHA.
Татьяна не принимает свой алгоритмический код одна: Андрей и Руслана оставляют
независимые результаты. Перед тегом 27 декабря Варвара сверяет SHA сборки и отчёта.
