# Демонстрация после реализации v0

Сейчас каркас этот сценарий не выполняет. Владелец сценария - Татьяна, показывают Илья/Леонид.
Используйте собственную короткую вокальную запись; технический tone.wav годится только для smoke.

1. Показать URL стенда, версию и SHA. Объяснить задачу сервиса за 20 секунд.
2. Загрузить MP3/WAV 10-20 секунд. Показать проверенную длительность и плеер.
3. Ввести 3 короткие собственные строки; задать времена, одну границу взять из плеера.
4. Нарочно задать неверный интервал, увидеть ошибку, исправить.
5. Сохранить и обновить страницу: данные остаются.
6. Запустить рендер; показать queued/running. Заранее измерить ожидание на стенде.
7. Просмотреть MP4 со звуком, скачать, открыть локально.
8. Показать GitHub Release, командный вклад и ограничения v0.

Если стенд недоступен, воспроизвести на локальном Compose. Записанный ролик можно
приложить как демонстрационный материал, но нельзя выдавать за текущую работу сервиса.
