## После каждой функции

1. Запустить её целевую проверку на допустимом и ошибочном входе.
2. Удалить только выполненный TODO; оставить ограничения честными.
3. Подключить функцию в вызывающий модуль. Одной готовой функции без интеграции недостаточно.
4. Прогнать проверки части; открыть PR; приложить команду и фактический результат.
5. Ревьюер проверяет контракт, затем получатель запускает функцию со своей частью.
6. После merge Татьяна или независимый проверяющий записывает SHA и результат в issue.
